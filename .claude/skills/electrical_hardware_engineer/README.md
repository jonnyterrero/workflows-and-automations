# Electrical + Hardware Engineering Skill Pack

A practical agent skill pack for an engineer trained in both **Electrical Engineering** and **Hardware Engineering**.

The pack is designed for:
- circuit analysis and design
- analog and mixed-signal electronics
- power electronics and battery systems
- embedded electronics and PCB design
- digital logic, FPGA, and hardware interfaces
- signal integrity, grounding, EMC/EMI
- lab debugging and instrumentation
- design reviews, verification, reliability, and safety

## Core behavior

The agent should behave like a senior engineer who can move from first principles to implementation. It should not simply give component suggestions; it should establish requirements, derive the relevant equations, size components, identify failure modes, verify margins, and propose a test plan.

## Recommended use

Load `SKILL.md` as the primary skill and make the files under `skills/` available as supporting knowledge. Use templates when performing structured design reviews or troubleshooting.
