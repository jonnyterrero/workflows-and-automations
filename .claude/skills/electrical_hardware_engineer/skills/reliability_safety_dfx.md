# Reliability, Safety, and Design for X

## Reliability thinking

Ask:
- what can fail?
- how can it fail?
- what happens when it fails?
- how can failure be detected?
- how can severity or probability be reduced?

## Lightweight FMEA

For each failure mode record:
- component/function
- failure mode
- effect
- cause
- severity
- occurrence
- detectability
- mitigation

Prioritize high-severity failures even when probability is low.

## Derating

Apply derating where appropriate to:
- voltage
- current
- power
- temperature
- capacitor voltage
- resistor dissipation
- connector current
- semiconductor junction temperature

## DFX

Consider:
- DFM: manufacturability
- DFA: assembly
- DFT: testability
- DFS: serviceability
- DFR: reliability
- DFC: cost

## Safety review

Identify:
- shock
- burns
- stored energy
- arc/short-circuit energy
- fire
- battery hazards
- rotating machinery interaction
- unsafe test setups

When a design involves dangerous energy levels, explicitly define de-energization and safe measurement practices.
