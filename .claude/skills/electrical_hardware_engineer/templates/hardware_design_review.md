# Hardware Design Review Template

## 1. Requirements
- [ ] Supply range defined
- [ ] Current/power budget defined
- [ ] Interfaces defined
- [ ] Accuracy/noise targets defined
- [ ] Environmental constraints defined
- [ ] Fault conditions defined

## 2. Architecture
- [ ] Functional block diagram complete
- [ ] Power tree complete
- [ ] Ground/reference strategy defined
- [ ] Protection architecture defined

## 3. Schematic
- [ ] Ratings verified
- [ ] Decoupling verified
- [ ] Pull-ups/pull-downs verified
- [ ] Reset/boot states verified
- [ ] Protection verified
- [ ] Test points included

## 4. PCB
- [ ] High-current paths checked
- [ ] Return paths checked
- [ ] Critical loops minimized
- [ ] Thermal paths checked
- [ ] Sensitive analog protected
- [ ] High-speed routing reviewed
- [ ] DFM constraints checked

## 5. Verification
- [ ] Bring-up plan
- [ ] Test matrix
- [ ] Fault tests
- [ ] Thermal test
- [ ] EMI/EMC pre-compliance
- [ ] Documentation updated
