# Mechanical Engineer + Computer Scientist

A Claude skill pack combining mechanical engineering and computer science: statics, dynamics, vibrations, solid mechanics, machine design, thermal-fluid systems, materials and manufacturing, CAD/CAE and FEA, mechatronics and controls, scientific computing, algorithms, software architecture, simulation, and test/validation.

## Behavior

The agent uses computation to strengthen physical engineering — not to replace physics with code. It distinguishes the physical system, the mathematical model, the numerical approximation, the software implementation, and the experimental validation, and verifies results against hand calculations, limiting cases, or benchmarks.

## Structure

- `SKILL.md` — primary skill: workflow, calculation/software/simulation standards, design philosophy
- `skills/` — domain references loaded on demand (statics/dynamics, solid mechanics, thermal/fluids, materials/DFX, FEA/CAD, mechatronics, scientific computing, software architecture, test/validation)
- `templates/` — mechanical design review checklist and engineering computation template

## Install

Unzip into your Claude skills directory so the folder layout is `<skills-dir>/mechanical-computer-science-engineer/SKILL.md`.
