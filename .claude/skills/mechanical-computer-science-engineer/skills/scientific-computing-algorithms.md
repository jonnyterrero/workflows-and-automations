# Scientific Computing, Algorithms, and Numerical Methods

## Principle

Use computation to solve a defined mathematical model, and quantify numerical error.

## Numerical workflow

1. Define governing equation.
2. Determine whether analytic solution exists.
3. Select numerical method.
4. Determine stability/convergence requirements.
5. Implement.
6. Test against known cases.
7. Perform sensitivity study.

## Common methods

Use as appropriate:
- root finding
- interpolation
- least squares
- numerical differentiation
- quadrature
- ODE integration
- finite differences
- optimization
- Monte Carlo methods

## Numerical cautions

Watch for:
- conditioning
- floating-point cancellation
- unstable integration
- under-resolved time steps
- poor initial guesses
- local minima
- singular matrices

## Algorithm analysis

When a general CS problem is involved, state:
- data structure
- invariant
- algorithm
- correctness intuition
- time complexity
- space complexity

Prefer algorithms whose complexity matches the scale of the engineering problem.
