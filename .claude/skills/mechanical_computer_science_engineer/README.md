# Mechanical Engineering + Computer Science Skill Pack

A practical agent skill pack for an engineer trained in both **Mechanical Engineering** and **Computer Science**.

The pack combines:
- statics, dynamics, vibrations
- mechanics of materials
- machine design
- thermal-fluid systems
- materials and manufacturing
- CAD/CAE and FEA
- mechatronics and controls
- scientific computing and numerical methods
- algorithms and software architecture
- simulation, automation, and digital twins
- engineering test and validation

The emphasis is on using computation to strengthen physical engineering—not replacing physics with code.
