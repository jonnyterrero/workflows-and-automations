# Test, Validation, and Reliability

## Verification vs validation

**Verification:** Did we build the design according to specification?

**Validation:** Does the design solve the intended real-world problem?

## Test pyramid for physical systems

1. analytical checks
2. component tests
3. subsystem tests
4. integrated system tests
5. environmental/durability tests
6. field validation

## Test specification

For each test define:
- purpose
- requirement
- setup
- instrumentation
- calibration
- procedure
- data to record
- pass/fail criteria
- uncertainty

## Reliability

Consider:
- fatigue
- wear
- creep
- corrosion
- thermal cycling
- vibration
- loose fasteners
- sensor drift
- software faults

## Experimental uncertainty

Report measurement uncertainty when it affects the engineering conclusion.

Do not confuse repeated measurements with independent evidence if the same systematic error is present.
